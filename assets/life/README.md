# 灵伴 2.0.0 房间与生活物品素材

本目录包含 34 个独立物品 PNG 与 4 个床前景 PNG。四套家具各 6 件，另有 4 种食物、3 种玩具、初始食盆、初始软垫和成长纪念摆件。

素材由内置 imagegen 生成，经过透明精灵裁切与画布归一化；未使用第三方家具图片。制作日期为 2026-11-02。每件物品的稳定 ID、资源文件、尺寸、落地点、占地、交互点和摘要见 [manifest.json](manifest.json)。本目录不拥有商品价格、等级、库存或养成状态。

## 显示契约

- 所有 PNG 为 512×512 RGBA；背景透明，物体完整，不应使用会裁切内容的 `object-fit: cover`。
- `anchor` 为相对于完整画布的归一化落地点，当前统一为 `{ x: 0.5, y: 0.9375 }`。将这个点对齐房间地面位置，可避免高矮物件底部错位。
- `footprint.width/depth` 使用逻辑房间格，不是像素。地毯属于地面层；其他物件按落地点前后排序。
- `rotations: [0]` 表示只提供当前前左侧视角。没有制作其他方向，不能把简单镜像标为 90 度旋转。
- `contentBounds` 为主图中实际物体的像素边界，允许商店缩略图按内容缩放。不能因此改变房间的统一落地点。
- `interaction` 与 `placementSurface` 为归一化的交互/放置参考位置；实际角色比例、路径和碰撞由房间逻辑控制，接线后需在真实房间中验证。

## 床的前景遮挡

四张床有对应 `*-foreground.png`，与主图尺寸和位置完全一致。先画完整床，按 `interaction` 放置睡眠角色，再画前景层，可让角色被近侧被褥和床框遮挡。

前景层由同一图的近侧部分分离，避免材质错位；分界位置记录为 `foregroundCutY`。这是一套固定视角的分层素材，不支持任意旋转或自由镜头。

## 制作与检查

专用脚本为 `scripts/build-room-assets.py`，依赖 Python 与 Pillow，只处理已有图，不调用图像服务。默认读取本地 `.artifacts/v2-art-room/` 下的五张精灵表：

```powershell
python scripts/build-room-assets.py
```

也可通过 `--source` 指向另存的精灵表目录。精灵表文件名是 `atlas-warmwood.png`、`atlas-forest.png`、`atlas-ocean.png`、`atlas-star.png`、`atlas-daily.png`。

生成请求、原始精灵表和检查预览保存在本地美术工作目录；运行时只需要本目录资源。脚本使用透明区域的连通物体检测进行裁切，避免生成图轻微偏离网格时截断家具。仅清除 1–3/255 的透明背景噪点，保留半透明泡泡凳的材质。

检查涵盖 34 个稳定 ID、RGBA、尺寸、透明背景、画布内边界、四张床前景、文件摘要以及组合预览。真实 Windows / Android 场景中的拖动、碰撞、遮挡和角色使用由对应应用验收覆盖。
