# Familiar · 灵伴 1.1.0

2026-10-21。Windows x64 与 Android ARM64 同步更新；Android 沿用 1.0.0 正式证书和包名，可直接覆盖安装。

## 本次变化

- 修复离开 Android 控制器后，气泡或键盘成为当前窗口而影响手机操作的问题。无障碍工具定位实际前台应用，重新验证窗口、节点指纹和有效期；服务断开时清除连接状态，重新连接后启动独立核心。控制器不拥有无障碍和宠物的生命周期。
- 修复窗口事件清理与节点读取争用、控制器绑定失效后的恢复，并补齐暂时隐藏宠物时的刷新循环。系统权限与受保护页面仍由 Android 管理。
- 新增 GitHub 正式版检查：启动后检查，随后每六小时检查；设置中也可手动检查。Android 控制器和桌面宠物、Windows 控制器和宠物均显示更新入口。预发布迁移包不会作为正式更新。
- 点击更新自动选择 Android ARM64 APK 或 Windows x64 安装器，显示下载进度、取消和重试。安装包必须通过 GitHub 资产的 SHA-256 校验；重启后恢复已下载状态，打开前再校验一次。
- Android 安装前核对包名、更高版本与相同签名，再交给系统安装器；首次需要在系统页面允许此来源安装应用，返回后再次点击“安装更新”。Windows 打开已下载安装包所在位置，由用户运行安装器。
- Android 气泡回车直接发送，支持输入法发送回调、单独换行提交和实体回车；Shift＋回车保留换行，不把候选词组合过程当作发送。
- 优先保持“宠物 → 回复气泡 → 输入气泡”的排布，输入始终在回复下面。回复宽度稳定，长内容内部滚动；空间不足时临时上移宠物，给下面的气泡留位置，关闭后恢复原位置，原拖放偏好不改。
- 修复靠边外划容易被系统取消的问题，在移动阶段识别收起。启用吸附后立即停靠最近边缘；外划或闲置后只露出半个小脑袋，透明窄窗口同步缩小。手动外划不依赖自动吸附开关；点按或向内拖动展开，手动收起不会马上被原聊天重新撑开。

## 升级

1.0.0 尚无内置更新入口，需从本次发行页面手动安装一次。安装 1.1.0 后，后续正式版才会通过应用内提醒下载。旧的 `.debug` 包仍按 [0.3.1 迁移说明](v0.3.1-migration.md) 导出和导入，不能跨签名覆盖。

Windows 更新前退出宠物和控制器，保留自己的数据目录。Android 直接覆盖正式包，不卸载；现有模型配置、Keystore 凭据、记忆和历史保留。发行文件不含用户密钥或数据。Windows 仍未提供 Authenticode 签名。

## 验收范围

类型检查、207 项核心测试，Windows 真实发行包基础交互回归，Android 正式包中的真实 DeepSeek 应用启动、无障碍观察与点击、日程创建和拒绝分支已验证；测试使用独立会话和日历，结束后恢复原配置。更新逻辑覆盖正式版筛选、系统匹配、显式下载、重复点击、错误文件、篡改、取消与重启恢复；真实 GitHub ARM64 APK 下载与 SHA-256 校验成功。更新界面在 Android 窄屏、竖屏、横屏及 Windows 宠物入口经过浏览器交互检查。

最终正式 APK 的实体回车、设备输入法发送回调、长回复滚动、真实横屏、上下气泡与宠物互不遮挡、四边半头像、关闭自动吸附后的手动收起、闲置十秒收起均实测通过，记录位于 `.artifacts/release-1.1.0/android-ui/`。输入法、原模型、历史与宠物设置已恢复。后台记录位于 `.artifacts/release-1.1.0/background/`：正常后台回收控制器进程，等待九十秒后，真实 DeepSeek 完成应用启动、界面观察、点击及重新观察，整个测试持续 116 秒，Runtime PID 保持，控制器进程没有重开。

本地验收资料不作为发行资源上传。真 ARM 手机、HyperOS 长时保活和不同厂商输入法仍需设备验证；用户在系统里“强行停止”应用后，需要手动重新打开。

## 实现与依据

更新业务位于 `plugins/app-updates`，平台适配负责文件交接和原生提醒，没有进入 Kernel，也不作为模型工具暴露。更新请求只读取公开发行信息，不携带模型密钥或会话。

- [GitHub Releases API](https://docs.github.com/en/rest/releases/releases)：正式版和资产下载地址、摘要。
- [Android AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)：系统绑定、窗口与缓存接口。
- [Android InputConnection](https://developer.android.com/reference/android/view/inputmethod/InputConnection)：输入法提交与发送动作。
- [Android PackageManager](https://developer.android.com/reference/android/content/pm/PackageManager)：安装来源许可与安装包资料。
