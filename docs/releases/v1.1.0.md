# Familiar · 灵伴 1.1.0

2026-10-21 · Windows x64 / Android ARM64

## 更新内容

- **Android 后台手机操作**：修复离开控制器后，无障碍操作受气泡或输入法窗口干扰的问题，改善服务断开后的连接恢复。
- **版本更新提醒**：宠物和控制器会提醒 GitHub 新正式版。点击后自动选择当前平台的安装包，支持进度显示、取消与重试，并校验下载文件的完整性。
- **气泡聊天**：回复显示在上方，输入气泡固定在下方；长回复内部滚动，空间不足时临时调整宠物位置。使用设备输入法，回车直接发送，Shift＋回车换行。
- **边缘收起**：宠物靠边后，向屏幕外轻划即可只露出半个小脑袋；也可设置闲置自动收起。轻点或向内拖动展开，手动收起无需开启自动吸附。

## 下载与升级

- Windows 安装版：`Familiar-1.1.0-Setup-x64.exe`。
- Windows 免安装版：`Familiar-1.1.0-win-x64.zip`。
- Android：`Familiar-1.1.0-arm64.apk`，支持 Android 9 及以上的 ARM64 设备。
- `SHA256SUMS.txt` 提供安装包校验值。

**从 1.0.0 升级需要手动安装一次。** 自 1.1.0 起，后续正式版可通过应用内提醒下载。

Android 正式版可直接覆盖安装，无需卸载；现有模型设置、记忆和历史继续保留。下载后由系统确认安装，首次可能需要允许此来源安装应用。早期 `.debug` 开发包请按 [旧版数据迁移步骤](https://github.com/mengxingGG/My-Familiar/blob/main/docs/releases/v0.3.1-migration.md) 导出、导入。

Windows 更新前退出宠物和控制器。安装版运行安装程序；免安装版替换程序文件并保留自己的 `.familiar` 数据目录。应用内下载完成后可打开安装包所在文件夹。

## 兼容性

Android 已在支持 ARM64 转译的模拟器上验证；真实 ARM 手机、HyperOS 长时间后台运行及不同厂商输入法仍需设备验证。系统“强行停止”应用后，需要手动重新打开。

Windows 安装包暂未提供 Authenticode 签名。
