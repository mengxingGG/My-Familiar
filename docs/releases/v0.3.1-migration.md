# Familiar Android v0.3.1 迁移版

这是给旧 Android 开发包补发的一次过渡更新。包名仍为 `app.familiar.mobile.debug`，版本号 `0.3.1-migration`、versionCode `3001`，使用旧版证书，支持覆盖 `0.3.0` 并保留数据。它不是后续正式版的签名路线。

迁移包与已验证旧包的证书 SHA-256：`db62654d1f0f55e0c78914849522bba8d056c7501d210bd51c0e6ff99ad67b32`。若旧包来自其他开发者自行构建，需用那个旧包的原始证书构建迁移版，不能强行覆盖不同签名的安装。

1. 下载 `Familiar-0.3.1-migration-arm64.apk`，覆盖安装旧包，先确认原模型和记忆仍在。
2. 打开“设置 → 数据迁移”，设置至少 10 字符的密码，再次输入确认；按需勾选“包含模型密钥”，点击“加密导出单文件”。在 Android 系统选择器中选择保存位置。
3. 保留旧包，安装正式 `Familiar-1.0.0-arm64.apk`。两者可并存。
4. 在正式版“设置 → 数据迁移”选择刚导出的 `.familiar` 文件，输入密码，预览记忆数量、冲突、模型地址和密钥数量，核对后确认导入。
5. 确认正式版模型和记忆可用，再决定是否卸载旧版。悬浮窗、通知、日历、无障碍和其他系统授权需在正式包中重新配置。

文件整体使用 AES-256-GCM 加密，PBKDF2-HMAC-SHA-256 600000 次、随机盐与随机 IV；格式及头部也经认证。密码不存入导出文件，丢失密码无法恢复。

迁移范围：核心规则、日记、教训、扩展记忆、模型连接及可选模型密钥、昵称/性格和宠物基本设置。当前版不迁移聊天原文、附件、第三方账号登录、用户工具白名单、系统权限或 Android Keystore 原文件；导入后的模型密钥重新进入正式版 Keystore。模型凭据只匹配其原连接地址，不发送到迁移服务。

导入会替换同名记忆和模型设置，保留其他记忆；先保存一份加密恢复点，密码与本次文件一致。“恢复上次导入前状态”会完整替换当前记忆和模型设置，包含移除恢复点中没有的记忆；操作前会再次确认。恢复点可在应用私有目录内保留到下一次导入，不对外公开。

边界：加密文件最多 25 MiB，记忆总量 20 MiB，单份记忆 2 MiB，最多 5000 份；核心规则仍遵守 2000 字符上限。失败时不会截断资料后冒充成功。若资料超限，应先在旧版整理，保留原数据再导出。
