# Familiar · 灵伴 2.0.0

2026-11-17 · Windows x64 / Android ARM64

## 更新内容

- **养成系统**：宠物会饿、会困、会想玩。吃饭、睡觉、玩耍各有动画；基础口粮可从背包自动取用，长期缺粮只改变外观，不限制聊天、语音或工具。
- **灵石与成长**：每日签到、在线陪伴和日常对话可获得灵石与经验，1–20 级逐级奖励口粮，3/5/8/12/20 级解锁里程碑摆件。离线最多补算 72 小时需求，不补发离线收益。
- **小窝**：可布置的房间，暖木小屋、苔光森林、月湾海居、星灯书房四套家具按单品购买。支持拖动、键盘微调、取回和保存；宠物会走到床上休息。
- **背包与商店**：4 种食物、3 种玩具；特殊食物可单独设置是否自动食用。
- **新形象**：新增 DeepSeek 鲸鱼娘、GPT 银发小龙娘、Claude 橙发读书少女三个 Q 版形象；七个原有角色补全十五类动作动画。十个形象共享同一份养成进度，换形象不改变钱包、等级、房间、模型或性格。

## 下载与升级

- Windows 安装版：`Familiar-2.0.0-Setup-x64.exe`。
- Windows 免安装版：`Familiar-2.0.0-win-x64.zip`。
- Android：`Familiar-2.0.0-arm64.apk`，支持 Android 9 及以上的 ARM64 设备。
- `SHA256SUMS.txt` 提供安装包校验值。

1.1.0 用户会在宠物和控制器中收到更新提醒，也可手动下载。Android 正式版使用与 1.1.0 相同的签名，可直接覆盖安装；Windows 更新前请退出宠物和控制器。

原有配置、凭据、记忆和会话格式不变，养成数据保存在新增的独立文件中，首次启动获得 80 灵石、8 份基础口粮、食盆和软垫。Android 加密迁移文件暂不包含养成档案，不能用作养成备份；暂无跨设备同步。

## 兼容性

Android 正式包已在 Google Android 15 模拟器上用隔离数据完成养成和既有功能回归。物理 ARM 手机、厂商后台回收策略和长时间功耗仍需设备验证；部分第三方 Android 14 模拟器上核心启动失败，原因待查。

Windows 发行包与 2026-11-02 通过养成和既有功能冒烟测试的构建使用相同源码，本次重新打包后未重跑打包冒烟测试。

家具目前只有单一朝向。Windows 安装包暂未提供 Authenticode 签名。
