# Familiar v0.2.0 · 伙伴、记忆与连接

Windows 10/11 x64 预览版，发布于 2026-09-22。相比 [v0.1.0](v0.1.0.md)，本版新增飞书、GitHub、更多角色和独立性格，以及会话上下文压缩。

基础记忆、Skill/MCP、七种模型接入、历史会话、主动关怀和工具权限已经包含在 v0.1.0 中；本版对这些能力作了改进，不将它们重复列为新增模块。

## 下载与启动

从 [GitHub Release](https://github.com/mengxingGG/My-Familiar/releases/tag/v0.2.0) 选择：

| 文件 | 用法 |
| --- | --- |
| `Familiar-0.2.0-Setup-x64.exe` | 安装向导，可选择目录；从开始菜单启动 |
| `Familiar-0.2.0-win-x64.zip` | 完整解压，运行 `Familiar.exe` |
| `SHA256SUMS.txt` | 两个程序附件的 SHA-256 校验值 |

运行发行版不需要另装 Node.js、Electron 或 Windows SDK。首次打开设置，选择模型并保存 API Key；双击宠物输入，Enter 换行，Shift+Enter 或按钮发送。飞书和 GitHub CLI 依赖通过插件页面的安装按钮下载到宠物目录，不随程序预装，也不包含任何账号登录资料。

## 新增

- **飞书插件**：官方 CLI 依赖安装、网页登录 / 扫码授权、已有机器人接入、用户或机器人身份的办公工具，以及需要配对的私聊通道。缺少 scope 时显示缺失项，支持增量授权和完整办公能力授权。
- **GitHub 插件**：浏览器登录或 Token，连接官方远程 MCP；新配置默认支持业务读写，也可切换为只读。MCP 按分页获取完整工具列表。
- **五个新角色**：绵绵、栗栗、方方、柚子、点点，加上小森、月团共七种；均有六种语义动作。形象与性格独立选择，新增温柔、细致、直白、热情、简洁五种预设，也可以跟随角色推荐或保留自定义设定。
- **会话压缩**：默认应用上下文上限 256K、80% 自动整理，两个数值均可调整；实际窗口同时受模型能力约束。结构化交接摘要与日记分开保存，保留完整历史和近期原文，可在历史管理中查看摘要、按索引回查原文。用户仍在同一会话中继续聊天。
- README 增加六张实际应用展示图，以及可复用的隔离拍摄脚本。

## 改进与修复

- 日记不再逐轮抄录全部聊天，由模型通过 `memory_diary` 挑选重要经历；核心偏好、日记和教训分开保存。同日相同日记正文去重，旧文件保持原样。
- 移除固定的八次工具往返和单批工具数量限制；任务以模型完成或用户取消结束，继续检查模型上下文预算。
- 飞书和 GitHub 的正常业务创建、编辑、删除不再统一按 Shell 拦截，仍遵循用户显式设置的权限规则；账户、认证、组织或企业管理边界继续保留。飞书官方 scope 和资源访问授权仍需要用户或管理员实际授予。
- 修复收到响应头后仍可能等待的流式读取取消行为，完成请求后清理超时计时器；Windows Skill 目录移动遇到临时文件占用时进行有限重试。
- 旧版自定义性格按原文保留，新增预设不会覆盖用户已有设定；桌面与飞书私聊上下文和会话授权分别管理。

## 从 v0.1.0 升级

1. 从托盘退出 Familiar，并关闭控制器。
2. 保留 `%APPDATA%/Familiar`。它包含配置、密钥、会话和 Runtime 的 `Local State`；系统加密密钥不能只备份单个 JSON。
3. 安装版使用新安装包更新，记忆等资料继续位于 `%APPDATA%/Familiar/home`。免安装版保留原程序旁的 `.familiar`，只替换程序文件，或将该目录复制到新解压目录中。
4. 重启后检查原模型连接、角色、记忆和历史。旧日记不会自动删除或重写；新聊天才采用重要日记策略。已有性格会作为自定义设定保留，可以手动切换到新的预设。

从源码切换到安装版时，项目 `.familiar` 与安装版的家目录不同；需要沿用记忆时请复制到 `%APPDATA%/Familiar/home`，遇到同名文件先比较。正常升级不需要清空配置或重新安装 Skills。

## 验证范围与当前边界

发布前通过 TypeScript 检查、76 项逻辑/协议测试、固定 CLI 依赖检查，以及打包后的五组真实窗口测试（基础交互、Agent、日常陪伴、角色与插件、会话压缩）。这些检查使用隔离数据和本地模拟模型。

另外用原始 v0.1.0 发行程序创建演示数据，再切换到本版程序：配置、自定义性格、手填上下文、核心记忆、旧日记、自定义 Skill 和会话均保留；旧密钥密文不变，仍能成功解密并用于本地模拟模型。该验证覆盖程序读取旧数据，不等同于实际安装器的升级向导验收。

已检查 app.asar 的 1752 项和 ZIP 的 79 项，没有用户运行数据；ZIP 中程序、app.asar 和定位组件的摘要与已测目录一致。定位组件自检成功，没有请求真实定位。外部服务的真实验证范围单独记录在 [插件说明](../10_Familiar_飞书GitHub与角色性格.md) 和 [验收记录](../05_Familiar_本地预览验收记录_v0.1.md)。

飞书已验证真实文档搜索、读取目录和授权不足提示；GitHub 已验证连接与工具发现。真实私聊消息收发、办公创建/编辑/删除和远端仓库写入尚未全面验证，不能将模拟测试等同于这些服务全部可用。飞书能否访问具体资源取决于授权 scope 和资源权限。

压缩是模型生成的有损整理，不能保证每个细节不遗漏；完整历史可回查。目前在用户发送前触发，尚不支持单轮工具执行中的自动压缩。未知模型窗口暂按 32768 处理，确认后可手动设置。

发行包未代码签名。实际安装器的安装/升级/卸载交互、系统定位、多屏 DPI、真实中文输入法及长期资源占用仍需进一步手工验证。尚无语音、3D 或自动更新。

```powershell
npm ci
npm run check
npm run check:cli
npm run package:release
npm run smoke:packaged
npm run smoke:agent:packaged
npm run smoke:experience:packaged
npm run smoke:integrations:packaged
npm run smoke:context:packaged

```

Windows 构建需要 Windows 10/11 SDK。构建命令不会自动上传；源码提交、版本标签、附件校验与 GitHub Release 发布分别进行。
