# Familiar v1.0.0 · Windows 与 Android 正式版

2026-10-21。Android 正式接入 Familiar 的共享插件核心，与 Windows 一同发布 1.0.0。此版本保留桌面伙伴的形象、性格、记忆与模型选择，把手机上的入口改为可常驻的悬浮宠物和原生对话气泡。

## 下载

- Windows x64：`Familiar-1.0.0-Setup-x64.exe` 和 `Familiar-1.0.0-win-x64.zip`。
- Android ARM64：`Familiar-1.0.0-arm64.apk`，Android 9 / API 28 及以上，包名 `app.familiar.mobile`。
- 同一 Release 提供 `SHA256SUMS.txt`。旧版附件继续保留。

Android 使用独立发行密钥签名，v2/v3 签名均验证，关闭应用/JNI/WebView 调试，开启 R8 优化。Windows 安装版与 ZIP 暂无 Authenticode 签名。没有将调试包更名为正式包，没有内置任何用户 API Key。

## 主要变化

- Android 控制页与宠物 Runtime 独立运行，前台服务提供可见停止入口；关闭控制页后仍能用原生气泡连续聊天。
- 气泡保留桌面纸色与绿色风格，支持多行输入、流式回复、停止、草稿和会话切换；边缘吸附、闲置/外滑收成小脑袋可独立设置。
- 共享七类模型、角色/性格、历史、记忆、Skills、上下文压缩和大型工具轮次原文回查。
- 工具权限统一为全自动、有限执行、审批制度和全部拒绝；联网搜索、内置日记/记忆始终允许。审批支持精确白名单、一次、当前会话全部和拒绝，当前会话授权不能用于其他渠道或会话。
- 手机应用查找与启动、无障碍观察/点击/输入、截图和手势保留目标时效检查；拒绝、取消、目标变化不自动重放。
- 系统日历包括本地日历管理、筛选分页、日程增删改查、全天/重复/单次安排、参会人、提醒方式、忙闲与私密级别；系统时钟接入标准闹钟、重复、铃声/振动、稍后提醒、倒计时与列表交接。已有时钟项目的完整读取、永久修改/删除等使用无障碍观察操作，接收应用不支持的 Intent 如实报告不可用。
- 设置页提供密码加密的 `.familiar` 单文件导出、预览导入和恢复点。旧版另发同签名 0.3.1 迁移包，正式包重建 Keystore 中的模型凭据，不复制原 Keystore。
- 系统图片/文件选择器、剪贴板、PDF/Word 本地提取，独立 STT/TTS、设备朗读、常规与 Live 语音、离线唤醒及按需权限。
- HTTP MCP、GitHub Token/设备授权入口、飞书私聊与机器人/个人办公、关怀与大致位置能力已接入。相关云服务由用户自行配置。
- Android 办公使用官方 CLI 的 Go/Wasm 构建及受限原生文件代理；旧原生 Go/Houdini 路线不再作为生产执行器或失败回退。
- 可选 GitHub 配置损坏不再阻断核心和宠物启动，只有明确确认后才修复原文件并清理旧绑定。
- 修复正式构建中 JNI 名称被 R8 改写导致核心不能启动的问题，并保留 WebView JavaScript 接口协议名称。

## 验证

类型检查与 **201 项核心测试**通过。Windows 1.0 真实发行目录的基础交互、Agent、陪伴、角色/插件和上下文五组回归通过，使用隔离数据，不修改用户 Windows 配置。新增四模式、授权隔离、备份篡改/密码错误和跨安装恢复测试；Android 原生审批按钮及迁移表单另有真实浏览器与设备操作验收。

用户明确授权后，以其 Familiar 的真实 DeepSeek `deepseek-flash` 验证原生气泡连续聊天和重启后的 Keystore 恢复；实际模型调用过 Exa 并根据真实结果续答。本次发行进一步从气泡测试实际应用启动、无障碍观察/点击/重新观察，以及真实 CalendarProvider 的单次创建/回读；应用启动和日程写入均包含批准与拒绝分支，独立测试日历与会话在结束后清理。关闭调试、开启 R8 的正式 APK 上重复通过，待发布文件 SHA-256 为 `392f0e5e2b7d6adf3dcc056f24c5f152b91332cb9a18a8e67913abfa4c5b8634`。新增日历管理/参会人/提醒/筛选原生实测、重复日程单次改期/取消及忙闲/私密字段回读也已通过。真实 Fossify Clock 创建每周闹钟和倒计时后观察到唯一测试项目；它的无深链接解除 Intent 不可用，未冒充解除成功。

跨签名迁移实际通过 Android 系统选择器完成旧版加密导出、正式版导入，错误密码不改数据；移除目标测试密钥后，导入的密钥完成真实 DeepSeek 调用。恢复点回滚和原正式版配置/记忆/密钥恢复均通过。旧版 0.3.0 与迁移版证书摘要相同，覆盖安装前后原设置及加密凭据摘要未变。原生审批卡的精确白名单、同会话跨工具允许、新会话重新确认、拒绝及全部拒绝模式也已实点验证。

## 升级与资料

Windows 用户先退出宠物和控制器，保留 `%APPDATA%/Familiar` 及其 Runtime `Local State`；安装版直接更新，ZIP 版只替换程序文件，保留自己的 `.familiar` 目录。已有模型、记忆与历史继续使用。

Android 正式包使用新的 `app.familiar.mobile` 身份；旧包 `app.familiar.mobile.debug` 可保留。先升级旧包到 [0.3.1 迁移版](https://github.com/mengxingGG/My-Familiar/releases/tag/v0.3.1-migration)，在设置中加密导出，再由正式版选择文件、输入密码、核对预览并导入。迁移记忆、日记、模型配置及可选模型密钥、昵称/性格和宠物基本设置；本次不含聊天原文、附件、第三方登录和系统权限，见 [完整范围](v0.3.1-migration.md)。系统悬浮窗、通知、日历和无障碍需按需重新授权；录音需手动开始。后续正式版使用同一发行密钥更新。维护者应私下备份本机 `.release-keys/` 整个目录，私钥和口令不进入 Git 或 Release。

## 已知范围

- 首轮按用户要求使用模拟器；设备为 x86_64 + Houdini ARM64 转译，交付 APK 仅 arm64-v8a。ELF 与 APK 原生库 16 KiB 对齐已校验，但真 ARM/16 KiB 页设备、HyperOS 保活、真实中文输入法和长时功耗尚未实测。
- Android 系统的受保护页面可能隐藏第三方悬浮窗，安全窗口禁止截图；这些系统边界仍需人工交接，不绕过保护。系统“强行停止”后需用户手动重新打开。
- 真机相机、真人语音/回声与云 Live、真实飞书/GitHub/高德业务仍依赖相应设备、账号和配置；已有夹具或协议测试不冒充这些业务已通过。
- Android 不支持桌面的 stdio/npm MCP；无 3D 或自动更新。Windows 与 Android 保留各自的平台工具与权限差异。

## 构建

Windows：Node.js 24、npm、Windows SDK，执行 `npm ci`、`npm run check`、`npm run package:release`。

Android：JDK 17、Android SDK 36 / Build Tools 36.0.0、NDK 27.0.12077973、CMake 3.22.1 与 Rust stable 的 `aarch64-linux-android` 目标。原生依赖准备和正式签名命令见 [Android 构建](../android-ui/BUILD_ANDROID.md)。开发默认使用 `npm run android:build`；正式包使用 `powershell -File scripts/build-android.ps1 -Release`。测试组件单独构建、同签名安装，在结束后卸载，不作为发行附件。
