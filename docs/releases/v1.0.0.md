# Familiar · 灵伴 1.0.0

2026-10-21 · Windows x64 / Android ARM64

Familiar 首个 Windows 与 Android 同步正式版。Android 提供常驻悬浮宠物和原生对话气泡，与桌面版共享模型、角色、记忆和工具能力。

## 主要功能

- Android 控制器与常驻宠物分别运行，可在其他应用上通过气泡连续聊天、接收流式回复、停止生成和保留草稿。
- 七个原创形象、独立性格、历史会话、分层记忆、Skills 和上下文压缩。
- 全自动、有限执行、审批制度、全部拒绝四种工具权限模式；审批支持白名单、允许一次、允许当前会话全部和拒绝。联网搜索、内部日记与记忆始终允许。
- 手机应用查找与启动、无障碍观察和操作、截图与手势；系统日历管理、日程增删改查、重复安排、参会人和提醒。
- 标准闹钟与倒计时入口；已有闹钟的完整编辑等功能通过无障碍操作兼容时钟应用，具体支持情况取决于接收应用。
- 密码保护的单文件数据导出、预览导入和恢复点。
- 图片与文件附件、语音配置、HTTP MCP、GitHub 和飞书接入，相关服务需自行配置。

## 下载

- Windows 安装版：`Familiar-1.0.0-Setup-x64.exe`。
- Windows 免安装版：`Familiar-1.0.0-win-x64.zip`。
- Android：`Familiar-1.0.0-arm64.apk`，Android 9 及以上，包名 `app.familiar.mobile`。
- `SHA256SUMS.txt` 提供安装包校验值。

## 升级与迁移

Windows 更新前退出宠物和控制器，保留 `%APPDATA%/Familiar`；免安装版同时保留程序旁的 `.familiar` 目录。

Android 正式包与早期 `app.familiar.mobile.debug` 开发包可并存。旧版需先安装 [0.3.1 迁移版](https://github.com/mengxingGG/My-Familiar/releases/tag/v0.3.1-migration)，加密导出数据，再在正式版中预览并导入。迁移范围及步骤见 [数据迁移说明](https://github.com/mengxingGG/My-Familiar/blob/main/docs/releases/v0.3.1-migration.md)。系统权限需要在正式包中重新授权。

## 兼容性

Android APK 仅提供 ARM64 架构，已在支持 ARM64 转译的模拟器上验证；真实 ARM 手机、HyperOS 保活和不同厂商输入法仍需设备验证。语音和第三方账号业务依赖设备、网络与所配置服务。Android 不支持桌面的 stdio/npm MCP。

此版本尚无内置更新入口。后台无障碍修复及更新提醒已在 [1.1.0](https://github.com/mengxingGG/My-Familiar/releases/tag/v1.1.0) 提供，建议手动升级。

Windows 安装包暂未提供 Authenticode 签名。
