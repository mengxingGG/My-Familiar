# Familiar v0.3.0 · 声音、图片与分层记忆

Windows 10/11 x64 预览版，发布于 2026-10-11。相比 [v0.2.0](v0.2.0.md)，本版让宠物能听会说、能看图，记忆改为分层整理，控制器换了新的界面。

## 下载与启动

从 [GitHub Release](https://github.com/mengxingGG/My-Familiar/releases/tag/v0.3.0) 选择：

| 文件 | 用法 |
| --- | --- |
| `Familiar-0.3.0-Setup-x64.exe` | 安装向导，可选择目录；从开始菜单启动 |
| `Familiar-0.3.0-win-x64.zip` | 完整解压，运行 `Familiar.exe` |
| `SHA256SUMS.txt` | 两个程序附件的 SHA-256 校验值 |

运行发行版不需要另装 Node.js、Electron 或 Windows SDK。首次打开控制器，在“模型连接”里选择模型并保存 API Key；语音另需在“图片与语音”里点“使用推荐配置”，并分别保存识别和合成接口的 Key。

## 新增

- **语音对话**：喊宠物的名字唤醒（本机识别，不上传待机音频，可自定义唤醒词和灵敏度）；唤醒后默认持续对话，直到手动结束；它说话时开口即可打断；输入框的麦克风按钮可把话转成可编辑的文字。合成支持 PCM 流式播报，收到第一段声音就开口。
- **宠物自己的声音**：两套原创参考声音“森铃”“团团”，可固定或按性格推荐，换主模型或语音模型时保持同一种声线；五段性格试听随程序附带，不调用接口。
- **Live 接口**：可配置 OpenAI Realtime 兼容接口或 Gemini Live。目前仍由主模型代为回答，并需使用服务商音色；开始前检查模型、Key 和声音身份，不满足时提示，不静默切换模式。
- **图片与文件**：输入框和历史会话可以添加图片、PDF、Word、文本，也能粘贴图片；可选允许宠物在你提问时截取当前屏幕，手动截图只授权一次，不持续录屏。
- **分层记忆**：核心规则（最多 2000 字）随对话注入，只放必须遵守的规则和长期偏好；教训和扩展记忆按主题分文件，开头写明“何时读”，由程序汇总成索引；日记仍只记重要经历。宠物可以原地改写或删除条目；写满时请它合并，不再自动精炼改写。新增条目前会查重，判断为重复或取代时把原条目交给宠物决定。
- **新的控制器**：左侧小窗显示当前宠物和它的状态（思考、睡觉、语音对话），颜色随形象变化；设置按“陪伴、对话、能力、系统”分组；工具确认改为每页顶部的提示条；形象改为带预览的卡片选择。界面沿用角色插画的配色，头顶气泡与输入条同步更新。
- README 重写，七张展示图按新界面重拍，新增“图片与语音”。

## 改进与修复

- 记忆在会话开始时固定为快照，宠物写入新记忆不再打破提示词缓存；压缩、新建会话、重启或你在控制器里编辑记忆时刷新。
- 判断、检索和每轮记忆用量写入 `%APPDATA%/Familiar/data/memory-trace-日期.json`，保留 30 天，用于后续改进的对比，不是记忆本身。
- 展示图生成和集成测试不再依赖另外下载的浏览器；升级检查脚本支持从 v0.2.0 开始。
- 新增真实语音链路检查脚本 `scripts/voice-live.mjs`，需显式授权并使用隔离副本，不打开真实麦克风。

## 从 v0.2.0 升级

1. 从托盘退出 Familiar，并关闭控制器。
2. 保留 `%APPDATA%/Familiar`。它包含配置、密钥、会话和 Runtime 的 `Local State`；系统加密的密钥不能只备份单个 JSON。
3. 安装版直接用新安装包更新，记忆仍在 `%APPDATA%/Familiar/home`。免安装版保留程序旁的 `.familiar`，只替换程序文件，或把该目录复制到新解压的目录中。
4. 重启后检查模型连接、角色、记忆和历史。

关于记忆的变化：

- v0.2.0 的核心记忆最多 3000 字。超过新上限 2000 字的旧核心会完整保留并照常使用，“记忆与日记”页面会提示整理；整理到 2000 字以内之前，宠物新增核心条目会被拒绝，删减总是允许。
- 旧的按时间命名的教训文件原样保留，在索引里按标题列出；之前自动精炼留下的备份文件不进入索引。
- 语音和图片设置、语音接口的 Key 与主模型分开保存，升级后需要单独配置。

## 验证范围与当前边界

发布前通过 TypeScript 检查、105 项逻辑与协议测试、固定 CLI 依赖检查，以及打包后的五组真实窗口测试（基础交互、Agent 与记忆、日常陪伴、角色与插件、会话压缩）。图片与语音、本机唤醒用源码版的窗口测试和离线语音样本检查。这些检查使用隔离数据和本地模拟服务。

用 v0.2.0 实际程序生成隔离演示数据后切换到本版：配置、性格、手填上下文、可用的旧加密密钥、超限旧核心（原样保留并提示整理）、旧日记、旧格式教训、自定义 Skill 和会话均保持。该验证覆盖程序读取旧数据，不等同于安装器升级向导的验收。

已检查 app.asar 的 3026 项：包含七个角色和七个声音文件，没有用户运行数据；ZIP 中的程序与 app.asar 和已测目录一致。

语音链路单次测试样本：识别约 3 秒出文字、约 13 秒开始播放，插话约 0.6 秒停止。已进行本机麦克风唤醒、持续对话与插话测试；速度取决于模型、语音接口和网络，不作为性能保证。

尚未验证：Live 账号的真实通话、远场与扬声器回声的系统测量、窄窗口布局、安装器的安装/升级/卸载交互、多屏 DPI 和长期资源占用。当前识别在说完一句后整体转写，不是逐字识别；原生 Live 的直接回答尚未实现。发行包未代码签名。尚无 3D 或自动更新。

## 重现构建与检查

```powershell
npm ci
npm run check
npm run check:cli
npm run package:release
npm run smoke:packaged
npm run smoke:agent:packaged
npm run smoke:experience:packaged
npm run smoke:integrations:packaged
npm run smoke:context:packaged
npm run smoke:voice
npm run smoke:wake
# 可选：将 v0.2.0 免安装包解压到隔离目录后，验证旧数据升级
node scripts/upgrade-smoke.mjs .artifacts/v0.2.0-baseline/Familiar.exe
```

Windows 构建需要 Windows 10/11 SDK。构建命令不会自动上传；源码提交、版本标签、附件校验与 GitHub Release 发布分别进行。
