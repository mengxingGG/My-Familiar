# Familiar v0.1.0 · Windows 首个预览版

Familiar 是独立运行的桌面伙伴。宠物在头顶气泡中回复，控制器负责设置和管理；关闭控制器后，宠物继续运行。

## 下载与启动

面向 Windows 10/11 x64，当前实际验证环境为 Windows 11 x64。

| 文件 | 用法 |
| --- | --- |
| `Familiar-0.1.0-Setup-x64.exe` | 安装向导，可选择安装目录；完成后从开始菜单启动 |
| `Familiar-0.1.0-win-x64.zip` | 解压后运行 `Familiar.exe`，保留整个目录 |
| `SHA256SUMS.txt` | 发布附件的 SHA-256 校验值 |

运行发行版无需另装 Node.js、Electron 或 Windows SDK。连接 npm/Node 类型的第三方 MCP 时，仍需该 MCP 声明的运行环境。发行包未进行代码签名，Windows 可能提示无法验证发布者。

首次启动后，从宠物旁的“设置”或托盘菜单打开控制器，选择模型服务、保存 API Key 和模型。双击宠物输入文字，Enter 换行、Shift+Enter 或点击发送。托盘右键可打开控制器、找回宠物或退出。

## 本版功能

- 独立宠物与控制器、两套 2D 占位角色、头顶输入和回复气泡、清晰托盘图标；外观实时应用，气泡默认 15 秒收起。
- OpenAI 兼容、OpenAI、DeepSeek、Gemini、Claude、OpenRouter、llama.cpp 七种接入；模型列表、温度、思考预算等参数、会话保持和缓存用量读取。
- 核心记忆、每日日记、教训文件，独立 Skill 与 MCP 管理；预置 Exa 和高德配置，密钥单独加密。
- 文件读写、搜索和 Shell 等基础工具；分类默认权限、本次授权、会话授权、精确白名单和全自动。
- 历史会话查看、搜索和继续；应用中聊天时宠物气泡安静。主动关怀总开关及用户自定义提醒。
- Windows 登录启动、设备位置与附近餐馆关怀的接口；位置需要单独授权，不按 IP 猜测。

## 数据与升级

模型密钥、配置和聊天记录位于 `%APPDATA%/Familiar`。密钥由当前 Windows 用户的系统密钥库加密，迁移时需一并保留 Runtime 的 `Local State`；复制到另一台电脑后可能需要重新输入 API Key。

安装版的记忆、Skill、MCP 和工具工作目录位于 `%APPDATA%/Familiar/home`。安装器写入分发标记，Runtime 据此选用用户目录，正常卸载不主动清理该目录。免安装版优先放在 `Familiar.exe` 同目录的 `.familiar`，目录不可写才回退到用户目录；配置与密钥仍在 AppData。

从源码版切换时，先退出宠物和控制器，备份 `%APPDATA%/Familiar` 及项目 `.familiar`。安装版如需沿用原记忆，将原 `.familiar` 内容复制到 `%APPDATA%/Familiar/home`，遇到已有文件先比较，避免覆盖。免安装版升级时保留原 `.familiar`，只替换程序文件。

## 验证与边界

源码通过 58 项单元、协议和集成测试及 TypeScript 检查。真实兼容 API 已完成模型目录、记忆工具、检索和主动问候验证。具体打包后的窗口验证记录见 [本地验收记录](../05_Familiar_本地预览验收记录_v0.1.md)。

本版是预览版，未承诺所有服务和设备均已实测：其他官方供应商、真实 llama-server、高德周边数据、Windows 实际定位授权、注销重登、多屏 DPI、实际中文输入法、长期资源占用和安装器交互流程仍需进一步验证。尚无语音、3D 或自动更新。

## 开发与发布

1. `npm ci`，安装 Windows 10/11 SDK。
2. `npm run check`。
3. `npm run package:release` 生成 EXE 和 ZIP，仅构建，不自动发布。
4. 顺序执行 `npm run smoke:packaged`、`npm run smoke:agent:packaged`、`npm run smoke:experience:packaged`，均使用独立测试数据。
5. 核对附件内容，生成 `SHA256SUMS.txt`，提交源码并将版本标签指向该提交，再上传 GitHub Release。

README 保留使用和构建入口；插件契约、继续开发与未完成工作见 [文档目录](../README.md)。
