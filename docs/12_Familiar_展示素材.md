## 重新拍摄

先按 [README](../README.md#从源码运行) 安装依赖并构建，然后在仓库根目录执行：

```powershell
node scripts/capture-showcase.mjs
```

脚本会启动独立的 Electron 宠物与控制器，配置演示角色、调用本地模拟模型、走一遍输入与回复，再拍摄设置、记忆和语音界面。只使用 Playwright 的应用页面截图，不捕获桌面、其他窗口或系统通知。演示实例仍会短暂显示在屏幕上，完成后自动退出。

- `FAMILIAR_DATA_DIR` 和 `FAMILIAR_HOME` 都指向本次 `.artifacts/showcase-时间戳/` 下的独立目录，不读取或覆盖日常使用的数据。
- 不需要 API Key，不调用真实模型、飞书或 GitHub，也不会更改系统开机启动设置。
- 记忆图只截取文件列表和编辑区，本机绝对路径显示在它上方，不进入截图；语音图停在页面底部保存栏上方。
- 原始截图、相对窗口位置、排版 HTML 和输出记录留在 `.artifacts/`，不会随源码提交。
- 七张发布图片写入 `docs/images/`。重新运行会替换这些图片。

如只需要调整构图和文案，编辑 `scripts/render-showcase.mjs` 后复用某次原始截图：

```powershell
node scripts/render-showcase.mjs .artifacts/showcase-时间戳
```

渲染器用随项目安装的 Electron 离屏排版（`scripts/showcase-host.cjs` 是不加载产品代码的空白宿主），不需要另外下载浏览器，也不重新绘制或修改截图中的控件、文字与功能状态。单张图高度上限 1500 像素，截图偏长时自动收窄展示框。封面和操作图根据捕获时的窗口尺寸、相对位置摆放宠物和气泡；背景不使用桌面照片。

## 更新后的检查

逐张打开图片，确认文字清晰、边缘完整、没有遮挡或旧版状态；确认没有个人路径、账号、密钥或私人对话。README 中的说明应与画面、源码功能以及发布版本一致。此拍摄流程仅验证演示交互和页面展示，不代表真实外部服务已通过联调。
