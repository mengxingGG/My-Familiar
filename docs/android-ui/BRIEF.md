# Android 移动界面规范

移动端延续桌面控制器的奶油纸色、鼠尾草绿、柔和描边、原创角色和贴纸式面板。信息架构适合触摸操作，不机械缩小桌面侧栏。

## 源码与边界

界面位于 `apps/tauri/ui/`，使用 HTML、CSS 和 TypeScript。`app.ts` 导出 `mountApp(bridge)` 与独立的 `mountApproval(bridge)`，卸载时清理订阅、事件、计时器和敏感输入。

业务只通过 [MobileBridge](../../packages/mobile-contracts/index.ts) 的请求与订阅访问。先订阅，再读取初始快照，忽略旧版本状态；界面不直接调用模型、申请系统权限或保存业务数据。独立预览使用相同接口与示例数据，并明确显示预览状态。

## 页面与交互

- 小窝：角色主视觉、常驻状态、模型连接提示、待处理任务和最近对话。
- 聊天：流式消息、停止、草稿、历史切换、附件和语音入口；状态与结果以核心快照为准。
- 能力：系统授权、断开与不可用状态、说明和适当的系统设置入口。
- 设置：伙伴、模型、记忆、Skills、MCP、第三方连接、数据迁移与版本更新。

角色列表、名称、图片与描述来自快照。模型配置按供应商和地址隔离，密码只用于一次提交，提交后清空，不回填、不记日志或写入浏览器存储。

输入草稿和附件按会话隔离，迟到结果只返回原会话。流式状态不得重建输入框或打断组合输入。系统选择或拍照只加入待发送附件，不立即交给模型。

## 审批表面

跨应用审批使用独立表面，展示完整目标和操作参数，固定显示操作按钮。支持添加白名单、允许一次、允许当前会话全部和拒绝。收起只隐藏卡片，不等于拒绝或取消。

任务字符串按纯文本展示。未知结果、目标失效、取消和拒绝采用不同状态；不由 UI 自动重试或批准。

## 适配与输入

覆盖窄屏、竖屏、横屏和平板，尊重安全区、动态视口与设备键盘。可点击区域至少 48 CSS px，保留可见焦点、读屏标签和减少动画偏好。

控制器聊天保留多行编辑与发送按钮；原生悬浮气泡使用回车发送、Shift＋回车换行。气泡优先从上到下排列宠物、回复、输入，长回复内部滚动。
