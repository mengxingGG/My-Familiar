# Android 前端集成

## 源码与入口

- `apps/tauri/ui/`：移动界面，导出 `mountApp(bridge)` 与独立审批表面的 `mountApproval(bridge)`。
- `packages/mobile-contracts/index.ts`：版本化快照、命令与错误类型，不依赖具体宿主。
- `packages/mobile-bridge/index.ts`：请求关联、超时、事件订阅、版本保护与错误脱敏。
- `apps/tauri/entry.ts` / `native-transport.ts`：真实宿主入口与 Tauri 传输。
- `apps/tauri/preview-entry.ts` / `preview/fixture.ts`：独立示例数据，不连接真实模型、不执行系统操作。

接口字段与命令的完整定义以 [公共契约](../../packages/mobile-contracts/index.ts) 为准。

## 构建与预览

```powershell
npm run mobile:build
npm run mobile:preview
npm run smoke:mobile
```

真实入口输出到 `dist/mobile-ui/`，预览输出到 `dist/mobile-preview/`，默认在 `127.0.0.1:4173` 提供服务。可通过 `FAMILIAR_MOBILE_PORT` 选择端口。预览只开放构建后的前端资源，不开放源码根目录。

普通浏览器缺少原生宿主时，生产入口显示连接不可用，不自动回退为预览。示例模式明确标注“预览 · 示例数据”；示例配置不需要真实密钥。

## 请求与快照

传输请求为 `{ protocolVersion, id, method, params }`，响应携带相同 ID 与协议版本。先订阅再请求 `snapshot.get`；同一连接的 `revision` 单调递增，旧快照被丢弃，宿主重建时重新建立连接。

请求超时只表示未收到结果，不自动重试变更命令。UI 不保存第二份业务权威状态；页面销毁清理订阅与监听，不承担后台任务生命周期。

真实路径为 Tauri → Kotlin 控制器 → 未导出的绑定服务及同 UID 私有 socket → 独立 `:runtime` 核心。平台适配负责 Android 权限、窗口、媒体与安全存储，共享插件负责模型、会话、记忆和工具。

## 消息、草稿与附件

`message.send` 携带点击时的 `conversationId` 和附件 ID，不能在执行时改用另一会话。`null` 由核心原子创建并选中新会话再发送。迟到失败只恢复所属会话的空草稿，不覆盖后续输入或其他会话。

输入框与待发送附件按会话保存于 UI 内存，快照只更新变化节点。选择文件、拍照、读取剪贴板或听写所得内容均绑定发起时的会话；被删除的会话不会因迟到结果复活。

`media.choose`、`media.camera` 等只导入待发送资料；取消返回空列表。预览按需读取，本地文本与元数据按纯文本显示。历史附件不批量预取，是否向模型发送由用户发送动作决定。

## 配置与凭据

Provider 档案按供应商和地址隔离。保存密钥只提交一次，不回填、不记录日志，不写入浏览器存储；快照仅投影 `keyConfigured` 等公开状态。类型或地址改变后不能沿用原地址的凭据提示。

识别、合成、实时语音、MCP 和第三方账号使用各自配置与凭据作用域。原生层通过 Keystore 及私有原子文件保存，不把令牌或自定义认证头暴露给普通快照。

## 权限、审批与常驻

能力卡以核心返回的已授权、未授权、断开或不可用状态为准。`capability.request` 发起适当的系统申请或设置跳转，打开系统设置不等于授权成功。

独立审批卡只接收必要任务快照，按纯文本展示完整操作参数。添加白名单、允许一次、允许当前会话全部和拒绝均交由共享授权系统处理；收起只隐藏窗口。

常驻、悬浮窗可见性和无障碍实际连接分别展示。控制器退出后后台由原生服务拥有，重新连接以新快照对齐。受保护页面、锁屏和失效目标不得由界面绕过。

## 语音与工具管理

听写按结果 ID 消费一次，回填原会话草稿；持续语音提供跨页面可见的停止入口。朗读仅处理已完成回复。旧宿主缺少某项能力时隐藏对应入口，不构造可用状态。

记忆、Skills、MCP、GitHub 与飞书管理通过契约请求完成。工具目录、执行与上下文预算归共享核心；大型工具原文分页回查，不在 UI 复制执行器或审批规则。

## 数据迁移与更新

迁移必须由设置页显式发起，使用系统选择器、加密文件与导入预览；密码错误或读取失败不改现有数据。

`updates.state/check/download/cancel/open` 提供版本检查、进度、取消和安装包交接。界面只展示投影后的更新状态，不执行未校验文件。Android 安装由系统确认，Windows 打开已下载文件的位置。

## 验证

浏览器检查覆盖窄屏、竖屏、横屏、返回栈、焦点、表单、草稿、迟到请求、审批与更新状态。原生输入法、悬浮窗、后台生命周期和实际业务另做设备测试，见 [Android 兼容性与测试](../20_Familiar_Android验收核对.md)。
