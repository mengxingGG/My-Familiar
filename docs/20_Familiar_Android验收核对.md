# Android 兼容性与测试

适用版本：1.1.0。APK 仅包含 `arm64-v8a`，最低 Android 9 / API 28，目标 API 36。

## 已验证范围

平台测试使用 API 34、支持 ARM64 转译的模拟器。该结果不能替代真实 ARM 手机的兼容性、厂商保活或功耗测试。

| 功能 | 测试范围 |
| --- | --- |
| 气泡聊天 | 连续多轮、流式回复、停止、草稿、长回复滚动、竖屏与横屏、输入在输出下方 |
| 输入法 | 设备输入法发送动作、实体回车发送、Shift＋回车换行、组合输入保护 |
| 边缘停靠 | 四边外划收起、半头像命中范围、点按展开、关闭自动吸附后的手动收起、闲置收起 |
| 独立常驻 | 控制器进程回收后 Runtime 与宠物继续运行，后台应用观察和操作 |
| 应用与无障碍 | 真实模型发起应用查找、打开、界面观察、点击及再次观察；批准与拒绝分支 |
| 系统日历 | 日历与日程读写、重复安排及单次例外、提醒与参会人；真实模型创建与拒绝 |
| 时钟 | 标准 Intent 在兼容时钟应用中的交接与结果观察；不支持的操作返回不可用 |
| 数据迁移 | 跨签名加密导出/导入、密码错误、恢复点、模型凭据重新加密 |
| 更新 | 正式版筛选、平台安装包匹配、下载完整性、取消和恢复；控制器与宠物更新入口 |
| 共享核心 | 类型检查及 207 项逻辑与协议测试通过 |

## 仍需设备或账号验证

- 真实 ARM 手机与 16 KiB 页设备；APK 原生库对齐检查不等于设备兼容性实测。
- HyperOS 等厂商后台策略、自启动管理、长时间驻留与功耗。
- 不同厂商输入法、相机、真实麦克风、远场回声及真实云 Live 通话。
- 飞书、GitHub、高德和云语音在实际账号权限与网络条件下的完整业务。

## 平台限制

无障碍服务需在 Android 系统设置中手动启用；悬浮窗、通知、日历、麦克风等按需授权。应用内工具审批不能替代系统授权。

系统受保护页面可能隐藏悬浮窗，安全窗口可能禁止截图。系统“强行停止”应用后需要手动重新打开。厂商后台管理与标准悬浮窗权限是不同设置，不能仅凭权限开关推断后台运行能力。

Android 没有公开的跨时钟应用完整数据库；已有闹钟的永久编辑等依赖兼容应用及无障碍观察。Intent 返回交接不等于业务已经完成。

## 复现与贡献

构建步骤见 [Android 构建与签名](android-ui/BUILD_ANDROID.md)。使用专用测试设备，运行前确认脚本指定的序列号、目标包名和所需权限。发布问题时附应用版本、机型、Android/系统版本、复现步骤与脱敏日志。

验收使用隔离数据，结束后清理测试资料并释放测试进程与资源。
