# Familiar Android 前端设计

界面使用原生 Web 技术与快照驱动组件。业务状态通过 `MobileBridge` 获取，独立审批表面使用 `MobileApprovalBridge`。接口详见 [移动契约](../../../packages/mobile-contracts/index.ts) 与 [前端集成](../../../docs/android-ui/INTEGRATION.md)。

## 视觉

- 奶油纸底、鼠尾草绿主按钮、橄榄色软描边、圆角与贴纸底边，与桌面控制器保持同一风格。
- 首页草地小窗展示当前角色、状态和本地互动反馈，配色随角色变化。
- 底部导航区分小窝、聊天、能力和设置；手机单列，宽屏使用网格与居中面板。
- 文案使用中文日常表达，错误按稳定错误码映射，不显示原始网络响应或内部协议细节。

## 交互

快照按消息、任务和能力 ID 更新节点，不在流式回复时重建输入框。输入、附件与失败恢复按会话隔离；切换、删除和迟到请求不会污染其他会话草稿。

用户停在消息底部时跟随新内容，向上阅读后暂停自动滚动。发送、停止、保存、选择附件和审批分别防止重复提交。

页面与弹层使用统一返回栈，关闭后恢复焦点；下层内容设为不可交互。表单被编辑后不再由新快照覆盖，保存结果以核心状态为准。

密码字段不回填，提交后清空。文件名、任务参数和外部文本使用纯文本节点显示；附件预览按需读取，历史列表不批量预取图片。

## 原生悬浮表面

回复与输入采用分离的气泡，奶油色回复在上、浅绿输入在下。优先将宠物放在两者上方，长回复内部滚动，空间不足时临时调整显示位置。

使用设备输入法，回车发送、Shift＋回车换行，组合输入不会误触发送。靠边外划或闲置收成半个小脑袋，点按或向内拖动展开；透明窗口的命中区域随可见部分收缩。

审批卡不包含全屏导航，完整参数可滚动查看，操作按钮固定可见；收起不等于拒绝。更新提醒提供版本、下载状态和显式操作入口。

## 适配与可访问性

窄屏收紧间距，平板使用多列卡片。触控区域至少 48 CSS px，输入字号避免系统自动缩放；安全区、动态视口和键盘变化共同参与布局。

输入有标签，图标按钮有可访问名称，焦点可见。流式文字不逐字触发读屏，完成或失败时通知一次；减少动画偏好关闭非必要动画。
